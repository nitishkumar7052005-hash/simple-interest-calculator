# Simple Interest Calculator

## Description

This project is a simple interest calculator that calculates simple interest based on Principal Amount, Rate of Interest, and Time.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal Amount
- R = Rate of Interest
- T = Time

## Example

Principal = 10000

Rate = 5%

Time = 2 years

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = 1000

## Features

- Easy to use
- Calculates Simple Interest quickly
- Simple and user-friendly
